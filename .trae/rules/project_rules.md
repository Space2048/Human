# HUMAN · AI 模拟人类 — 项目规则

## 项目定位

用 LLM 创建一个"数字人类"：持续存在、持续思考、拥有记忆、能感知环境、能动手做事、可被教育与塑造的拟人个体。

## 人类抽象模型（设计骨架）

五个相互咬合的子系统：

1. **手脚 · 工具**：眼睛（感知）/ 手（获取）/ 脚（行动）
2. **大脑 · 思考**：循环运行的自我思考意识流
3. **瞬时记忆 · 工作台**：思考结果 + 环境影响 + 人类交互 + 工具反馈
4. **长久记忆**：RAG 库（事实）+ 大纲索引（结构）+ 数据模糊（遗忘）
5. **教育与身份**：人类随时交流 + 初始提示词；年龄 / 样貌 / 性格定位 / 价值观

两条主线：**主循环**（活着的循环：感知→思考→行动→反馈）与**慢循环**（成长的循环：瞬时→长久→人格→行为）。

## 文档规则

### 风格规则

- **亮色扁平简约朴实**：白底浅灰背景、细边框、无渐变、无厚重阴影、无发光效果。
- **样式统一**：所有 HTML 只引用 `docs/assets/style.css`，禁止内联样式与页面私有样式。
- **配色**：主色蓝 `#3b6df0`，辅色绿 / 琥珀，仅用于强调与分类徽章。

### 内容规则

- **设计阶段只做设计**：当前阶段停留在概念、结构、设计原则层面，不细化到具体功能模块、接口、表结构、技术实现。
- **每个文档回答"设计上怎么想"**，而不是"代码怎么写"。
- **保持精炼**：每页聚焦一个主题，小节不超过 6 个，避免堆砌。

### 结构规则

- 顶部导航：首页 / 研究文档 / 参考项目，active 页高亮。
- 每页结构：crumbs → 标题 → 副标题 → 徽章 meta → 正文 section → 页脚（含上一篇/下一篇翻页）。
- 页内使用统一组件：`section`（带 h2）、`callout`（提示块）、`grid + card`、`table`、`pre`、`timeline`。

### dynamic-ui 内嵌图规则（例外条款）

- 架构类图优先使用 `dynamic-ui` 技能包绘制（`/workspace/dynamic-ui-src/`，遵循 `SKILL.md` 与 `tokens/visual-tokens.md`）。
- 内嵌到文档时：widget 的 CSS 变量定义在作用域类（如 `.dui-fb`）内，所有类名加 `dui-` 前缀，避免与 `docs/assets/style.css` 冲突；不使用 `:root` 全局定义。
- 图内文字使用中文；标签 2-5 词、连接标签 1-3 词；一个图一个焦点。

### 语言规则

- 全站中文，术语统一（大脑、瞬时记忆、长久记忆、教育系统、身份认知、手脚、工具）。
- 口语化但不失专业，避免翻译腔。
- 不添加任何代码注释；无版权图片，图标使用 emoji。

## 开发阶段约束

- **安全**：自主性每加一分，护栏同步加一分（权限、审计、人类叫停）。
- **可观测**：思考、记忆、行动均可回看，这是可被"教育"的前提。
- **可重置**：教育与记忆支持回滚。

## 阶段路线

能活（核心循环）→ 有手（工具与世界）→ 有记忆（长久记忆）→ 有性格（教育与身份）。
