1. 调研地图

我们围绕 HUMAN 的五个子系统，调研了一批开源项目。它们分属三大方向：

🏙

🧠

Letta (MemGPT)、Horcrux、Mind-Cloning-Engineering、LLM-BRAIN —— 记忆怎么存、人格怎么塑。

🖐

2. 模拟人 · 认知架构

Generative Agents（斯坦福 Smallville）

模拟人类行为的里程碑：25 个 Agent 住在一个虚拟小镇，自主起床、工作、社交，甚至组织派对。它验证了"记忆流 + 反思 + 规划"的完整认知架构，并证明了涌现的社会行为（信息传播、关系形成）不需要脚本，只需要好的记忆系统。

  • 记忆流记录一切经历；检索时按近期性、重要性、相关性三因素挑选记忆。
  • 反思：积累到一定量后，把散碎经历归纳为更高层的洞察，再存回记忆。
  • 规划：从长期计划到当天日程再到行动细节，层层分解。
✳
对我们的启发："记忆驱动行为"是可信模拟的核心——瞬时记忆、长久记忆、反思沉淀这三件事的循环，正是 HUMAN 大脑与记忆设计的原型。

Cognitiv（情感认知架构）

专注"情感化的心智过程"：记忆不只是检索，而是联想激活、情绪评价、心境起伏、不完美回忆。

  • 激活扩散：想到一个概念，连带激活相关的记忆。
  • 情绪评价：事件对照目标与价值观，产生有根据的情绪。
  • 记忆固化：相似经历被总结为"图式"，相似记忆产生自然的混淆。
✳
对我们的启发：它把"记忆的不完美"当作特性来设计。这与我们的"数据模糊"层一脉相承，也补上了情绪与心境这一维度。

MeKB-Sim（个人知识库驱动的多智能体模拟）

把每个 Agent 的知识库分成固定属性（职业、种族、教育、关系、语言风格）与可变属性（人格、长短记忆、情绪），事件发生后自动更新可变属性。它验证了"属性分层：稳定内核 + 动态状态"的可行性。

✳
对我们的启发：直接对应我们的"身份认知 + 教育系统"设计 —— 固定属性负责"是谁"，可变属性负责"正在如何变化"。

3. 记忆与人格

Letta (MemGPT) — LLM 操作系统

把 LLM 当作操作系统来管理自己的记忆：核心内存（人格 + 用户档案，常驻上下文）、回忆存储（近期历史，可检索）、档案存储（长期记忆，可插入可搜索）。Agent 自己决定记住什么、忘记什么、调回什么。

✳
对我们的启发："记忆像 OS 一样分级"是极好的心智模型 —— 常驻的（身份）、热的（瞬时）、冷的（长久）三级划分，与我们"瞬时 ↔ 长久"的边界设计互相印证。

Horcrux — 数字人格模拟框架

用 RAG 把真实人物的语料（如微博）变成"魂器"：抽取风格与观点，构建本地向量记忆库，让 Agent 持续模仿其说话方式与思维习惯。人格由配置驱动：简介、说话风格、口头禅、行为准则、示例对话。

✳
对我们的启发：人格 = 底稿 + 语料 + 检索的工程路径已被验证；它的人格外化（风格、口头禅、准则）正是我们"身份属性"的具体化样本。

Mind-Cloning-Engineering（心智克隆工程）

基于 Agent Skills 的思想：不把人格切碎成向量片段，而是把"一个人的心智"当作一个可移植的目录 —— 决策逻辑、价值权重、记忆都整理成结构化的"人"。

✳
对我们的启发：提醒我们"人"应该是一份有结构的档案，而非一堆散点。大纲索引层的定位与此一致。

LLM-BRAIN — 有向记忆图

用有向图模拟记忆网络：节点是知识片段，边是依赖关系；性格参数影响寻路，同一张图谱在不同性格下表现出不同推理。多角色协作（寻路、执行、验证、学习）。

✳
对我们的启发："性格影响记忆怎么被想起"这一思想非常珍贵 —— 人格不只决定表达，还决定注意与回忆的方向。

4. 动手与执行

UI-TARS / Agent TARS（字节）

纯视觉驱动的 GUI 智能体：直接"看"屏幕截图，输出点击、输入等操作，无需解析底层代码。与浏览器、命令行、文件系统无缝集成，能做复杂任务的规划与执行。

✳
对我们的启发：这是"图像识别眼镜"最直接的参照 —— 视觉即行动，跨平台、抗界面变动。

Browser Use / Playwright Agent 类项目

站点无关的自主浏览器 Agent：读可访问性树、点击输入滚动截图、逐步留证。要点包括：长任务检查点续跑、上下文预算管理（只保留重要步骤）、停滞检测与自纠、一次运行内的记忆（学导航模式但不跨任务污染）。

✳
对我们的启发：网络执行的工程经验几乎可以直接继承 —— "可续、可查、可纠正"以及运行内记忆与长期记忆的隔离。

Eko — 可控的生产级工作流

由清华、复旦、斯坦福合作的框架：自然语言构建多步骤工作流，支持浏览器与 Node 执行环境，核心是显式人工干预——人类可以在关键节点介入、审查、回退。

✳
对我们的启发：它就是"教育系统 + 安全边界"在工程上的证明 —— 人机协同的控制点是我们必须内置的。

VIGIL — 自我修复的反思运行时

一个"看守" Agent 的运行时：记录行为日志 → 评价为结构化情绪 → 得出"好/机会/问题"诊断 → 在护住核心身份的前提下，产出受限的自我改进。强调非 LLM 的确定性机制（衰减、阈值、策略）与 LLM 的高层推理分工。

✳
对我们的启发："自我维护 + 身份不可篡改"的护栏思路，直接回答了我们"教育改变人格，但怎么保证不崩坏"的疑问。

5. 汇总：他们给了我们什么

我们的设计点参考对象拿到的结论
思考循环 + 瞬时记忆Generative Agents记忆驱动的行为循环是可信模拟的核心
长久记忆三层Letta · Generative Agents · Cognitiv记忆分级存储；检索按近期/重要/相关；允许衰减与混淆
数据模糊（遗忘层）Cognitiv不完美的记忆是拟真特性而非缺陷
身份认知分层MeKB-Sim · Mind-Cloning-Engineering固定属性 + 可变属性；人格是结构化档案
教育系统Eko · Horcrux · VIGIL人类干预点内置；人格可被反复引导改变；护住核心身份
图像识别眼镜UI-TARS / Agent TARS视觉即行动，结构化优先、视觉兜底
浏览器搜索Browser Use 类可续跑、可留证、可纠正；运行内记忆隔离
安全边界Eko · VIGIL护栏与自主性同步增长；全程审计与人类叫停

6. 结论

参考项目验证了我们的大方向：记忆驱动行为、身份分层、工具闭环、人类可控。它们也提醒我们注意三个共识性的难点：

  • 上下文有限：无论记忆多好，"这一刻能想的事"始终有限 —— 所以瞬时记忆的容量感设计不可或缺。
  • 拟真与工程的张力：遗忘、情绪这类"拟真特性"会增加复杂度，需要像 Cognitiv、VIGIL 那样用确定性规则 + LLM 推理的分工来控制成本。
  • 安全是一等公民：自主性越强，护栏必须越早设计，而不是后补。
