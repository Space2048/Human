项目概述与目标

把"人"抽象成一个可运行的 LLM 系统 —— 先定义我们到底在模拟什么，再谈怎么实现。

理论基础 v0.1 2026-08-13

1. 一句话定义

HUMAN 是一个用大语言模型（LLM）驱动的"数字人类"项目：创建一个 Agent，它不是一个只会回答问题的聊天机器人，而是一个持续存在、持续思考、拥有记忆、能感知环境、能动手做事、可以被教育和塑造的拟人个体。

传统 Agent 是"任务驱动的"：你给我一个任务，我执行完就结束。而 HUMAN 是"存在驱动的"：它像人一样活着 —— 有自己的性格、自己的经历、自己的想法，人类可以随时与它交流，它也会在环境中自主行动。

💡
核心差异：从"回答问题"到"拥有生活"。衡量标准不是"答得对不对"，而是"像不像一个人"。

3. 设计原则

♾️

持续性优先

Agent 默认处于"在线思考"状态，而不是被任务唤醒。没有任务时它也在观察、记录、消化。

🧩

记忆塑造人格

没有记忆的模拟只是"扮演"，有记忆的模拟才是"成为"。记忆是人格的载体。

🌐

真实环境优先

不依赖封闭沙盒，直接面向真实世界：真实浏览器、真实 API、真实文件系统。

🫂

可教育性

人类用户既是观察者也是"监护人"，可以随时对话、引导、纠正，塑造它的成长。

🌗

拟真而非全知

允许遗忘、允许模糊、允许情绪偏差 —— 完美不是目标，真实才是。

🔒

安全边界

赋予自主执行能力的同时，必须有权限隔离、操作审计与人类叫停机制。

4. 成功标准（如何判断"像人"）

  • 人格一致性：同一问题在 30 天后与 1 天后的回答，仍体现同一种性格与价值观。
  • 记忆连续性：能主动提起过去的经历，并受其影响做出新的决策（如"上次被骗过，这次更谨慎"）。
  • 自主行动力：能自己决定"去搜索一下"、"看看窗外"，而不是坐等指令。
  • 情绪与状态：同一天内有自然的情绪波动，而非恒定不变的"客服语气"。
  • 可教育性：用户可以通过对话改变它的习惯与认知，且这种改变是持久的。
📌
借鉴 Generative Agents 的评估方式：用"图灵式访谈"让真人评判 Agent 的回答是否比"扮演该角色的人类"更可信。
