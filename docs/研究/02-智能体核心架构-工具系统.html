手脚 · 工具系统

人不能只靠脑子活着。工具系统是数字人类的"手脚与五官"：让它看得见、够得着、做得到。

手脚 设计层面 2026-08-13

1. 设计思想：给 LLM 一具"化身"

纯对话式 LLM 是"无实体"的，只能通过文字与世界互动。工具系统的意义，是给思考一个落点：让思维能感知世界，也能改变世界。

人类的能力链是"感知 → 获取 → 行动"。数字人类的工具系统对应三样"器官"：

👁

眼睛 · 感知

图像识别眼镜：理解画面、界面、图像，像人一样"看"世界。

🖐

手 · 获取

浏览器搜索：查资料、读网页、逛网络，数字人类获取信息的主要方式。

🦶

脚 · 行动

环境执行：在部署环境中运行、操作、落地，真正"动手做事"。

2. 眼睛 · 图像识别眼镜

人获取信息的第一通道是眼睛。数字人类需要一个"眼镜"来感知视觉信息，包括：

  • 看懂屏幕：界面、按钮、弹窗 —— 无论操作系统还是网页。
  • 看懂图像：用户发来的图、网页里的图，"看"出其中的内容与场景。
  • 看懂环境：来自真实镜头的画面，感知物理世界。
✳
设计取向：结构化优先，视觉兜底。能用稳定的结构化数据就不浪费"眼睛"，视觉专门处理结构化读不到的地方 —— 这与人眼加记忆的协作方式一致。

3. 手 · 浏览器搜索

数字人类需要"上网冲浪"，与人类查资料、读新闻、逛街是同一件事。设计上要回答几个问题：

  • 怎么搜：搜索 → 看摘要 → 决定深入哪里。
  • 怎么读：打开、浏览、提取正文，转换为可消化的信息。
  • 怎么记得住过程：中途失败、断线、改版，如何恢复继续。
  • 怎么不重复犯错：走过的弯路要留下痕迹，下次避开。
✳
设计取向：网络环境不可控，所以"过程可续、可查、可纠正"比"一步到位"更重要。

4. 脚 · 环境执行

数字人类必须在"部署环境"中真正执行，而不是停留在对话里。执行能力要分风险等级：

  • 只读：看文件、查状态、发请求 —— 低风险。
  • 受控写：在自己的范围内创建、修改 —— 中风险。
  • 全量执行：在授权范围内运行、调用、部署 —— 高风险。
⚠
设计原则：自主性越强，护栏越硬。权限分级、全程留痕、危险动作须经人类确认，这三点是架构的一部分，不是后补功能。

5. 工具的反馈闭环

工具系统不是单向的"调用 → 返回"。每一次使用工具的结果、错误、意外，都要回写到瞬时记忆，成为下一步思考的原料。如此才构成"看 → 想 → 做 → 再看"的循环。

工具系统与思考循环的接口设计，见 研究 03。

6. 设计要点小结

  • 工具 = 眼睛（感知）+ 手（获取）+ 脚（行动），三者各司其职。
  • 感知走"结构化优先、视觉兜底"的路线。
  • 网络执行要"可续、可查、可纠正"。
  • 环境执行要"分级授权、全程留痕、人类可叫停"。
  • 所有工具的结果必须回写瞬时记忆，形成闭环。
