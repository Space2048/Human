大脑 · 思考循环与瞬时记忆

人的意识不是一次问答，而是一条不停流动的河。这里设计的是那条河。

大脑 设计层面 2026-08-13

1. 核心思想：思考是一条河，不是一桶水

传统 Agent 的处理方式是"请求 → 回答"：一桶水，倒完就没了。而 HUMAN 的大脑是持续循环的：

  • 它不等待被提问，而是主动地、周期地运转。
  • 每一轮思考都以上一轮的结果为输入 —— 形成连续的意识流。
  • 思考可以被外部事件（环境、人类、工具）随时打断与插入。
✳
设计取向：把 LLM 的一次次调用，串成一条自我延续的思维线，而不是一堆孤立的问答。

2. 瞬时记忆：思考的"桌面"

瞬时记忆（工作记忆）就是思考循环的工作台——此刻"正在想"的一切都在上面。它的输入有四个来源：

🧠

思考结果

上一轮"想"出来的结论、疑问、念头，是意识流的燃料。

🌍

环境影响

环境里发生了什么：新信息、状态变化、时间流逝。

🫂

人类交互

人说了什么、做了什么、希望它做什么。

🛠

工具反馈

用工具得到的结果、错误、意外。

这四类输入汇入桌面后，大脑才能"看着桌面"进行下一轮思考。

3. 思考循环的节奏

思考不需要也不应该"每毫秒都烧脑"。设计上应区分不同的运行节奏：

  • 静默消化：没有新事件时，低频率地回顾、整理、发呆 —— 人发呆时其实也在整理记忆。
  • 应激响应：有新事件（人说话、环境变化、工具报错）时，立即插入处理。
  • 专注任务：认准一件事时，高频次连续运转，直到完成或放弃。
✳
设计取向：节奏自适应 —— 有事件就快，没事件就慢，像人的注意力一样有"张弛"。

4. 思考与记忆的关系

瞬时记忆不是孤立存在的，它夹在"外部世界"与"长久记忆"之间，扮演桥梁：

  环境 / 人类 / 工具
          │
          ▼
   ┌─ 瞬时记忆（工作台）──┐
   │  正在发生 · 正在想    │
   └──────────┬─────────┘
              │ 沉淀（值得记的）
              ▼
      长久记忆（RAG · 索引 · 模糊）
              │
              └── 回忆（需要时调回）──→ 回到工作台

一条瞬时内容经过思考，被判定"值得记"，就沉淀为长久记忆；而长久记忆在需要时又被调回桌面。这个双向通道的设计详见 研究 04。

5. 瞬时记忆的"容量感"

工作台是有限的，人同时能"端着"的东西就那么多。设计上要刻意制造这种容量感：

  • 有优先级：正在专注的事占大头，背景信息占小头。
  • 会过期：久未触碰的内容自然沉底，被新内容顶走。
  • 可被占用：一旦陷入深度任务，其余事件的注意力自然减弱。

这种"有限"不是缺陷，而是拟真的关键 —— 它让人格有了专注与分心的真实感。

6. 设计要点小结

  • 大脑是持续循环的意识流，不是一次性的问答器。
  • 瞬时记忆汇聚四类输入：思考、环境、人类、工具。
  • 思考节奏自适应：静默 / 应激 / 专注，张弛有度。
  • 瞬时 ↔ 长久是双向通道：沉淀与回忆。
  • 工作台刻意有限，以模拟人的专注与分心。
