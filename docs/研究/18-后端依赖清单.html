后端依赖清单

每一个依赖都是带着问题选的：它解决什么、有什么替代、为什么是它。

依赖 细化设计 2026-08-14

1. 依赖选型原则

  • 少而稳：只引入解决真实问题的库，优先选维护活跃、文档全的。
  • 可替换：核心依赖通过接口隔离（如向量库、LLM 层），换库不动业务代码。
  • 版本锁定：pyproject.toml 用约束范围（如 ^），不锁死也不放任。

2. 生产依赖

依赖用途为什么是它
litellm多模型统一接入层一套 API 接 OpenAI / Anthropic / 本地 Ollama，满足多模型混合（研究 13）
asyncio（标准库）事件驱动引擎调度器心跳、事件队列、打断恢复的底座；零第三方依赖
chromadb向量检索内嵌式、零部署、支持内存模式，首版最轻的 RAG 方案（研究 15）
fastapi + uvicornWeb 服务与 ASGI异步原生、类型友好，前端 SSE 接口的最简载体（研究 17）
sse-starletteSSE 流式推送思考流/状态栏/行动日志实时推送的标准实现
playwright浏览器自动化（手 + 眼）跨浏览器、可截屏、可读可访问性树（研究 16）
pydantic + pydantic-settings数据模型与配置Event/Turn/Impression 模型校验；配置从环境变量/YAML 加载
pyyaml配置解析身份档案、动机配方、节奏参数外置为 YAML（研究 13）
httpx异步 HTTP 客户端搜索引擎调用、外部 API 请求的异步实现
richCLI 美化首版 CLI 的终端渲染（思考流彩色输出、状态面板）
aiofiles异步文件读写记忆 JSON 文件、日志写入不阻塞事件循环

3. 开发依赖

依赖用途
pytest + pytest-asyncio单元/异步测试（引擎调度、记忆读写、工具安全）
ruffLint + Format 一体，快且零配置
mypy类型检查（核心引擎必须类型严谨）
pre-commit提交前自动跑 lint / 类型 / 格式

4. 可选/后续依赖

  • sentence-transformers 或 fastembed：本地嵌入模型（换掉远端 embedding，隐私/离线场景）
  • tiktoken：精确 token 计数（优化上下文预算时启用）
  • psutil：进程资源监控（长时运行的体检）
  • aiosqlite：SQLite 异步访问（记忆写入压力上来后启用）
  • websockets：未来远程操控升级时替换 SSE

6. 设计要点小结

  • 生产依赖 11 项，全部"带着问题选的"。
  • LLM 层与向量库通过接口隔离，可替换。
  • 开发依赖 5 项覆盖测试 / 类型 / 格式 / 钩子。
  • 后续依赖按需引入，不提前背负。
